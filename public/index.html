External Client App Guide

1
Create in Setup

Go to Setup ➔ External Client App Manager ➔ New External Client App.

2
Enable Client Credentials

Check Enable OAuth and Enable Client Credentials Flow. Assign the api and refresh_token scopes.

3
Assign Integration User

Select the execution user (e.g. an Integration User or Admin) in the Client Credentials settings.

4
Retrieve Keys

Copy the Consumer Key and Consumer Secret from the OAuth Information section and paste them here.
